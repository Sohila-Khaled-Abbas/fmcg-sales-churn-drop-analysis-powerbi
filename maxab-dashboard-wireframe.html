Visual & Storytelling Recommendations
SECTION 7.2 · DESIGN DECISIONS · NARRATIVE STRUCTURE · UX PRINCIPLES
📐 Layout Hierarchy Principles
01
Top-to-bottom reading order: KPI cards first (answer "what"), then trend charts (answer "when"), then breakdown (answer "where/why"). Never start with a table.
02
2/3 : 1/3 split for most rows — dominant chart left, supporting context right. Prevents visual symmetry from feeling like a spreadsheet.
03
5-card KPI strip is the maximum. Beyond 5, use a secondary strip or collapse less-important KPIs into a "More metrics" expandable panel.
04
Consistent color semantics across all pages: amber=revenue/commercial, teal=operational, green=positive/health, red=alert/negative, purple=retailer lifecycle.
📊 Chart Selection Rationale
01
Line chart for time series — never bar for continuous trends. Area fill adds weight to magnitude without clutter. Reserve bar for categorical comparisons.
02
Combo (bar + line) for dual-axis — always put the rate/% metric on the secondary axis as a line. Never two bars on dual axis.
03
Heatmap for time-pattern discovery — Day × Week matrices surface operational bottlenecks (e.g. Wed-Wk3 delivery spikes) that line charts miss entirely.
04
Cohort matrix for retention — diagonal reading reveals early churn signals. Color scale green→amber→red maps directly to business health intuition.
🗣 Narrative Flow per Page
P1
Executive Overview: Lead with revenue trajectory. Immediately juxtapose Sales vs Success Rate — healthy growth with degrading quality is a risk signal. Regional bar anchors "where we are".
P2
Delivery: Lead with SLA % (outcome), then drill to heatmap (cause). The parameter slicer lets ops teams test different SLA definitions in real-time.
P3
Churn: Start with net growth (positive), then reveal churn composition (nuance). Cohort matrix before segment table — pattern before detail.
P4
Drop Analysis: Single-problem page. Lead with the exact week and magnitude, immediately show which SKUs caused it. Action-oriented, not diagnostic.
P5
Commercial/Juice: Market share story — treemap for intuitive brand sizing, small multiples for trend direction per brand. Juhayna's decline is buried without multiples.
⚙ Parameter UX Guidelines
01
Always show active parameter value in the page subtitle (e.g. "SLA THRESHOLD: 2 WORKING DAYS"). Users must never wonder what the current setting is.
02
Default-value card: Place [SLA Threshold Label] and [Churn Window Label] measures as small cards above affected visuals so the current parameter is always visible.
03
Tile slicer preferred over dropdown for 1–7 range values — faster selection, no click-to-open. Set slicer to single-select. Show default value pre-selected.
04
Annotate affected visuals with a ⚙ badge (like the chart tag in Drop Analysis page) so users know which charts respond to the parameter — not all visuals do.
